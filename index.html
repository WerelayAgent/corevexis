Why is ETH outperforming SOL this week?

Market Intel Agent
openai/gpt-oss-120b
88% conf12/31/1969

Short answer. ETH's 7-day outperformance is being driven primarily by (1) restaking-narrative inflows, (2) reduced selling pressure on validator unstakes, and (3) DEX liquidity rotating back into ETH/USDC pairs from SOL meme pairs as memecoin velocity cooled.

Drivers

  • Restaking inflows continue accumulating into EigenLayer and AVS deposits, measurable through staking-deposit gateway calls (okx.onchain.gateway) and corroborated by 4 independent publications.
  • Net validator withdrawals are negative for the week, fewer ETH hitting circulating supply than entering staking contracts.
  • DEX flow concentration shifted into ETH/USDC on Base + Arbitrum, captured live by okx.dex.market.
  • SOL memecoin rotation appears exhausted (lower 24h velocity, declining new-pair counts), narrative momentum cooled per the narrative agent.

Risk to thesis

  • An L2 shock or restaking incident would invalidate (1). Validator queue dynamics are the cleanest invalidation signal.
  • This is intelligence, not financial advice.

From clone to thesis in minutes

Four steps. One key. Zero paid APIs.

CoreVexis ships as a Next.js app you self-host. Everything you see in the demo comes from public sources or your own configured providers.

01
Get the code

MIT-licensed. No accounts, no signup, no SaaS dashboard to attach to. You own the deployment.

$git clone <your CoreVexis repository> corevexis && cd corevexis
02
Drop in your Groq key

One environment variable. That's the only API token CoreVexis needs to route across GPT-OSS, Llama and any model Groq serves.

$echo GROQ_API_KEY=gsk_... >> project secrets
03
Boot the agents

Research, narrative, signal, security and market agents come online. OKX skills load. Public sources start being crawled.

$pnpm install && pnpm dev
04
Ask anything

Type a question. Watch the workflow execute step by step. Get a source-backed thesis you can audit, copy or hand to your team.

$open http://localhost:3000
